# コピー生成プロンプト設計(叩き台)

フェーズ2でAnthropic APIを使い、LPの見出し・本文コピーをLLMで生成する際の
プロンプト設計の叩き台。フェーズ1時点ではこのファイルは「設計メモ」であり、
実際にAPIを呼び出す実装は行わない。

## 前提: デフォルトのCRO仮説

以下は**実データが蓄積されるまでの初期仮説**として、コピー生成の前提知識に
組み込む。実際のA/Bテスト結果が溜まり次第、業種別・商材別の実データに基づく
知見で上書き・更新していく(固定ルールではなく、上書き可能な「初期値」として扱う)。

1. フォームの入力項目は少ないほどCVRが高い傾向がある(Baymard Instituteの知見)
   → コピー生成時、フォーム周りの案内文でも「入力はメールアドレスだけ」等、
     手間の少なさを明示する。
2. ファーストビューに社会的証明(利用者数、導入企業ロゴなど)を配置すると
   信頼性が向上する
   → hero直後のsocial-proofセクション向けコピーは、具体的な数字を含めるよう
     プロンプトで指示する。
3. CTAボタンの文言は「送信する」より行動後の利益を明示する方が効果的
   (例:「無料で始める」)
   → CTA文言生成時は「行為」ではなく「得られる結果」を主語にするよう明示的に指示する。
4. 訴求軸(価格・権威・感情など)によって刺さるターゲット層が異なるため、
   最初から複数パターンを試す前提で設計する
   → 1回の生成で終わらせず、同じ商材に対して複数の訴求軸バリアントを
     並行生成することをデフォルト挙動とする。
5. 長いLPの場合、最初の1画面での離脱率が高いため、価値提案は最上部で明確にする
   → hero部分の見出し・subcopyは、スクロールせずに価値提案が伝わる文字数
     (見出し30字程度、subcopy60字程度を目安)に収めるよう指示する。

## 入力(想定パラメータ)

- `product_name`: 商材名
- `target_persona`: ターゲット像(業種・役職・課題感など)
- `appeal_axis`: 訴求軸(`price` / `authority` / `emotion` など)
- `tone`: トーン(フォーマル / カジュアル 等)
- `key_facts`: 訴求軸を裏付ける事実(価格・導入実績・受賞歴・課題エピソード等)

## 生成対象セクションとプロンプト方針

### hero(見出し・サブコピー・CTA文言)
- 見出しは「機能」ではなく「得られる結果/ベネフィット」を主語にする
- サブコピーは「誰の・どんな課題を・どう解決するか」を1〜2文で
- CTA文言は行動後の利益を明示する動詞句にする(「〜する」で終わる送信系の
  文言を避ける)

### social-proof(社会的証明)
- `key_facts` にある具体的な数字(導入社数・受賞歴など)を必ず含める
- testimonialは実在感を出すため、氏名・役職(ダミーでも具体性のある形式)を
  伴う形で生成する

### pricing(料金訴求コピー)
- 各プランの説明文は「機能」ではなく「誰向けか」を明示する
- おすすめプランには、選ばれている理由を一言添える

### cta(最終行動喚起)
- hero の見出しと矛盾しない、最後の一押しとなる文言にする
- フォームの手間の少なさ(入力項目が少ないこと)を補足コピーで示す

## プロンプトテンプレート例(叩き台)

```
あなたはCRO(コンバージョン率最適化)に精通したコピーライターです。
以下の商材・ターゲット・訴求軸に基づき、LPの{{section}}セクション用のコピーを
生成してください。

商材名: {{product_name}}
ターゲット: {{target_persona}}
訴求軸: {{appeal_axis}}
トーン: {{tone}}
裏付けとなる事実: {{key_facts}}

# 出力ルール
- 見出しは30字以内、結果・ベネフィットを主語にする
- CTA文言は行動後に得られる利益を明示する動詞句にする(例:「無料で始める」)
- 事実に基づかない誇張(存在しない実績・数字)は含めない
```

## 出力フォーマット(想定)

`templates/*/sample.html` の `{{PLACEHOLDER}}` に対応するキーのJSONを返す想定。

```json
{
  "HERO_HEADLINE": "...",
  "HERO_SUBCOPY": "...",
  "HERO_CTA_TEXT": "..."
}
```
